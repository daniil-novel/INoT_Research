# E3 — Scaling on context length: empirical estimate of τ⋆

**Article reference:** §7.4. Tests Statement 2 (formula (7)) by locating
`τ⋆` empirically.

## What we measure

For each context length `|C0| ∈ {256, 1024, 4096, 16384}` and each
architecture `B0 / B2 / B3`, we compute `U_tok = pass@1 / (T̄ / 1000)` (per
formula (17)). We then locate the smallest `|C0|` at which the B3 curve
overtakes the B2 curve.

## How we estimate τ⋆

1. Build mean `U_tok` curves `Ŷ_B3(|C0|)` and `Ŷ_B2(|C0|)`.
2. Find the smallest `x` at which `Ŷ_B3(x) − Ŷ_B2(x) ≥ 0`. Linear
   interpolation between samples gives a continuous estimate.
3. **Bootstrap** task indices within every `(arch, ctx)` bucket
   (10⁴ resamples) and re-fit `τ⋆` per resample → 95% percentile CI.

## Pass condition for H1

The article's E3 success criterion is `τ⋆` finite and `< 16384`. We surface
`h1_practically_supported` accordingly.

## How to reproduce

```bash
# Article spec: 50 tasks × 4 ctx × seeds
python -m inot e3 --n 50 --seeds "42,123,456,789,1337"

# Quick pilot
python -m inot e3 --n 10 --seeds "42"
python -m inot view e3
```

Outputs in `results/e3/`:

- `tau_star.json` — point estimate, bootstrap CI and median, plus the share
  of bootstrap resamples that yielded a finite crossing
  (`finite_share`, low values → unstable estimate).
- `fig_utok_vs_context.png` — `U_tok(|C0|)` curves with τ⋆ marker.
- `fig_delta_utok_vs_context.png` — the difference curve.
- `runs.json`, `table.txt`, `summary.json` (per-bucket).

## Why this design

- A *single* point estimate of τ⋆ tells you nothing about its stability.
  The bootstrap pipeline gives an interval and a "finite_share" diagnostic
  that flags configurations where no crossing exists in the tested range —
  the empirical analogue of "hypothesis not supported on practical band".
- Plotting both `U_tok` curves and their difference makes both the absolute
  level and the regime change visible at a glance.
